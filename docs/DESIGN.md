Final Project Repository for Software Engineering

My Program is a simple Reservation Manager for a small boat harbor.

I decided to use the python library tkinter to make the gui and MySQL for the database. I chose those because they are what I know how to use. 

The four entities in the database are reservations, customers, boats and slips. Slips can only be added to the database through SQL because they don't come and go  on a regular basis like customers and boats do.  I used tkinter to make a menu page that allows the user to navigate to separate windows for four different functions. In the python code a connection is established to the database and a cursor is used to execute and commit the SQL queries. 

This was my first time creating any type of gui. Tkinter was what we were shown in class and it was easy enough to create something usable. I created the database first because I had done that type of thing before in a previous course and it seemed like the most logical step. I then use AI with the permission of my professor to bridge the gap between python code and that db. I used that code as a start and an example but the final product is 99 percent code that I wrote. Just the initial connection and a query or two were pasted in. I learned much of the methods I used on tkinter from John Elder at Codemy.com through his youtube channel.
